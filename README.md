# 🗒️ MyBlog System

A full-stack blog platform with AI-powered Tarot reading.

🌐 **Live Demo:** [myblog-system-fe.onrender.com](https://myblog-system-fe.onrender.com)

## ✨ Features

- 📝 Create and publish posts with image uploads
- ❤️ Like and comment on posts
- 🔮 AI-powered Tarot card reading

## 🛠️ Tech Stack

| Layer    | Technology         |
| -------- | ------------------ |
| Frontend | React + TypeScript |
| Backend  | ASP.NET Core (C#)  |
| Database | SQL Server         |

## 📁 Project Structure

```
MyBlog-System/
├── MyBlogFE/   # React + TypeScript frontend
├── MyBlogBE/   # ASP.NET Core backend API
└── MyBlogEX/   # Extensions (in progress)
```

## 🚀 Getting Started

### Prerequisites

- Node.js >= 18
- .NET SDK >= 8
- SQL Server

### Backend

```bash
cd MyBlogBE
dotnet restore
dotnet run
```

### Frontend

```bash
cd MyBlogFE
npm install
npm run dev
```
